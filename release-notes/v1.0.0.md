# Prepare to Co-op Edition v1.0.0

Play all of Dark Souls: Prepare to Die Edition together with up to three friends, from the Undead Asylum to the Kiln. Guests keep their own body and progress, deaths respawn at a bonfire, boss kills and area changes no longer end the session, multiplayer fog walls are gone, a bonfire rest resets everyone's world, progress made together carries home, enemies scale with the number of players, and evil spirits can invade. Inspired by Yui's Seamless Co-op for Dark Souls Remastered.

**Includes the DS1 PTDE FPS Unlock 1.7.0.** This `xinput1_3.dll` is the FPS Unlock plus the co-op, and `PTDE-FPS-Unlock.ini` holds the settings of both. If you have Prepare to Co-op, you have the FPS Unlock: do not install both.

## Install

1. Copy `xinput1_3.dll` and `PTDE-FPS-Unlock.ini` next to `DARKSOULS.exe` (`dxvk_d3d9.dll` only for the FPS Unlock's experimental DXVK). They replace the FPS Unlock's files if it is installed; set your FPS Unlock settings again in the new INI.
2. Set the same `Password` as your friends in `PTDE-FPS-Unlock.ini`.
3. Steam Deck and Linux: launch option `WINEDLLOVERRIDES="xinput1_3=n,b" %command%`.
4. Copy `Documents\NBGI\DarkSouls\DRAKS0005.sl2` to `DRAKS0005.co2` to bring an existing character (the co-op uses its own save file). Back up your saves.
5. Rest at a bonfire for the co-op items; host with the Blessed Eye Orb, join with the Crystal Eye Orb.

Everyone in a session needs the same version. While the co-op is on, Steam shows the game as Spacewar (app 480).

**Online play: no guarantees.** The mod changes the game in memory; use at your own risk. No responsibility is accepted for bans or lost progress (see the README and LICENSE).

Send `PTDE-FPS-Unlock.log` from every player in the session, and any `*-crash.dmp`, with a bug report.
