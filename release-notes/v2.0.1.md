# Prepare to Co-op Edition v2.0.1

A patch release with preliminary support for RTX Remix. **Plays with 1.5.0 to 2.0.0** (the co-op protocol is the same). Nothing changes for players who do not use RTX Remix.

**Includes the [DS1 PTDE FPS Unlock](https://github.com/zofrea1/DS1-FPS-Unlock-PTDE-Remastered) 2.4.1** (see its [release notes](https://github.com/zofrea1/DS1-FPS-Unlock-PTDE-Remastered/releases/tag/v2.4.1-PTDE-DX9)):

- **RTX Remix (preliminary)** (`YieldToRtxRemix = auto`, new). With RTX Remix installed beside the game (for example the Dark Souls PTDE RTX mod), the FPS Unlock leaves the picture to it: its resolution, depth of field, effects, water, colour, shadow, filtering, aspect and HUD scale settings, DXVK, the Direct3D-level speed-ups, the effects fixes, the cutscene camera fix, the mouse pointer and the intro skip are off, and the log says so. The frame rate, every gameplay fix, the controller fix and the refresh rate stay: Remix's own fullscreen mode now gets your display's highest refresh rate (`FullscreenRefreshRate`), where it set 60 Hz.
- **Setup with the Dark Souls PTDE RTX mod:** turn off its own frame rate unlock (`[FPSUnlock] Enabled=0` in its `rtx_comp\settings\remix-comp-proxy.ini`). DSfix is not compatible with the RTX mod.
- **Controllers with the RTX mod:** launched through Steam with Steam Input on, the game found no controller (Steam Input and the Remix bridge both wrap DirectInput, which the game uses to find controllers). Start `DARKSOULS.exe` directly, or turn Steam Input off for the game in Steam (Properties > Controller). The co-op still starts Steam itself.
- Tested 2026-11-15 with an early build of the RTX mod, co-op on: the RTX mod's picture, the frame rate and fixes, the controller and the full refresh rate.
- The log now says which slot the game binds for a controller and when its first input arrives, for controller reports.

## Install

Copy the files next to `DARKSOULS.exe`: `xinput1_3.dll`, `PTDE-Coop-FPS-Unlock.ini` and `dxvk_d3d9.dll`. Upgrading from 2.0.0: replace `xinput1_3.dll`; your INI keeps working. Everyone sets the same `Password` to play together. Back up your saves. Steam Deck and Linux: launch option `WINEDLLOVERRIDES="xinput1_3=n,b" %command%`.

**Online play: no guarantees.** The mod modifies the game in memory. Use at your own risk; no responsibility is accepted for bans or lost progress (see the README and LICENSE).
